9. Замыкания (Closure)

Почему внутренняя функция помнит count: при вызове createCounter() создаётся новое пространство переменных, и возвращаемая функция держит на него ссылку (замыкание), поэтому у каждого счётчика — своя, изолированная переменная count.

10. Деструктуризация, Spread и Rest

Разница: spread "разворачивает" элементы наружу (в массив/объект/аргументы функции), rest наоборот — собирает оставшиеся аргументы в один массив внутри параметров функции.

11. Optional Chaining и Default Values

|| срабатывает на любое "falsy" значение (0, "", false, null, undefined), а ?? реагирует только на null/undefined. Поэтому для чисел/строк, где 0 или "" — валидные значения, безопаснее ??.
